# Decision log

Short records of approved decisions ([ADR](https://adr.github.io/) style). Number files sequentially:
`NNNN-short-title.md`. Never rewrite an accepted record. Supersede it with a new one instead.

Template:

```md
# NNNN. Title

- Status: accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context

## Decision

## Consequences
```
