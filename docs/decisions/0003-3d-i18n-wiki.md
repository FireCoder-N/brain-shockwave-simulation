# 0003. 3D canvas, timeline, languages and wiki-style Project page

- Status: accepted
- Date: 2026-11-24

## Context

Feedback on the first design (ADR 0002): parameters felt cramped, the canvas should be 3D with
rotation and a navigation gizmo, the blow direction should be set with spherical angles, a
timeline should allow jumping to any frame, the site should be multilingual, and the Project page
should read like a wiki with a contents sidebar.

## Decision

| Topic          | Choice                                                                                                                                                          |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Layout         | Simulation window and panel split 50/50; playback bar docked inside the bottom of the window; legend under the HUD (top-left)                                   |
| Descriptions   | Behind an ⓘ icon (hover, focus or tap), rendered in a portal so panels never clip them                                                                          |
| Expand         | Full-page overlay with a floating, collapsible parameter panel; Esc closes                                                                                      |
| 3D             | React Three Fiber + drei: orbit controls, Blender-style axis gizmo (click an axis to view along it)                                                             |
| Blow direction | Physics/ISO spherical angles θ (polar from top), φ (azimuth from front) in a head-fixed frame (x front, y left, z up), plus off-center offset d and direction ψ |
| Timeline       | Record while running; scrub over recorded frames; ±1 frame steps; seeking pauses                                                                                |
| Languages      | react-i18next; English (default), Spanish, Portuguese (Brazil), Greek, Serbian (Cyrillic). Always English first, choice remembered                              |
| Translations   | Drafted by the assistant, marked for native review; interface translated now, articles later (English fallback with notice)                                     |
| Project page   | Markdown + KaTeX articles; sticky contents sidebar that highlights the current section; collapsible on mobile                                                   |

## Consequences

- three.js adds ~945 KB (raw) to a lazily loaded chunk; the rest of the page renders first.
- Every new UI string must be added to all five locale files (enforced by a test).
- `RUN_DURATION` and `FRAME_DT` in `playback.js`, and the timeline clock, are placeholders until
  the physics engine exists.
- The 3D colors in "preview" mode are illustrative (distance from the impact point), not results.
